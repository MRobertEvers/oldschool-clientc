# panel_icon.png -- the screenshot plugin's rail stone, as pixels.
#
# 30x30, the logical canvas the cache's own popout icons use (the Loot
# Tracker's panel_icon is popout_icons,3 at exactly this size), and drawn in
# their manner rather than camera.txt's: a one-pixel near-black outline, a
# shadow one pixel down and right of it, saturated mid-tones, light from the
# upper left. camera.txt is outline-less because it sits among the options
# icons; this one sits on the rail beside the loot bag and the XP chart, and
# without their outline it read as a hole in the column.
#
# A box camera rather than camera.txt's compact: the leather band is what
# makes it read at 30 pixels, where the grey body alone was a grey brick. The
# flash, the shutter and the lens keep camera.txt's places -- flash left,
# shutter right, lens centred -- so the rail and the viewport control are
# recognisably the same plugin.
#
# '.' is transparent. SOURCES.sh bakes this file into panel_icon.png; edit
# here, not there.
