# Ground Items price overrides: obj_id = price, one per line.
#
# The client has no Grand Exchange feed and never will -- what it knows is
# ObjType.cost, the cache's own base value, which for most items is the shop
# price rather than anything a player would pay. This file is where a plugin's
# author or a user corrects the ones that matter. Anything absent here is
# priced from the cache, and the high-alchemy figure is derived from whichever
# of the two applies (floor(price * 0.6), as the reference derives it).
#
# Deliberately a SECOND copy of the loot beam's table rather than a shared one:
# api.asset_load takes a bare filename and resolves it under this plugin's own
# directory, precisely so one plugin can never read another's files. The two
# tables answer the same question and are expected to be edited together.
#
# Ids are for cache.osrs239. Blank lines and # comments are skipped, and so is
# any line that does not parse -- one bad row must not cost you the rest.
