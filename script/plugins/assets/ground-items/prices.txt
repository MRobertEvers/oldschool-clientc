# Ground Items price overrides: name = price, one per line.
#
# The client has no Grand Exchange feed and never will -- what it knows is
# ObjType.cost, the cache's own base value, which for most items is the shop
# price rather than anything a player would pay. This file is where a plugin's
# author or a user corrects the ones that matter. Anything absent here is
# priced from the cache.
#
# Keyed by the item's NAME, matched case-insensitively against the name the
# booted cache gives the ground stack -- NOT by obj id. An id is a fact about
# one cache: this table used to be `obj_id = price` with "ids are for
# cache.osrs239" written here, and on any other cache a row either matched
# nothing or matched whatever item had inherited the number. Since an override
# is the only thing that can lift a stack to the loot beam's thresholds -- a
# shop price never reaches a million -- that made a beam structurally
# impossible on every lane but one, and a beam over the wrong item possible on
# the rest. The high-alchemy figure is derived from whichever price applies
# (floor(price * 0.6), as the reference derives it).
#
# A name a cache does not have simply never matches, which is the right answer
# and costs nothing. Blank lines and # comments are skipped, and so is any line
# that does not parse -- one bad row must not cost you the rest.
#
# Deliberately a SECOND copy of the loot beam's table rather than a shared one:
# api.asset_load takes a bare filename and resolves it under this plugin's own
# directory, precisely so one plugin can never read another's files. The two
# tables answer the same question and are expected to be edited together.
