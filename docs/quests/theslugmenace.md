# The Slug Menace -- pinned brief (2026-10-01)

Source: https://oldschool.runescape.wiki/w/The_Slug_Menace (Walkthrough, Rewards) and
https://oldschool.runescape.wiki/w/Slug_Prince. Quest Helper guide: helpers/quests/theslugmenace
(its swamp-paste steps are out of date; the wiki says paste cannot be used).
LostCity has no copy of this quest (post-2004).

Requirements: Wanted!, Sea Slug (and the long prerequisite chain); Crafting, Runecraft, Slayer, Thieving 30;
a Commorb. Rewards: 1 QP, 3,500 Crafting / Runecraft / Thieving xp, Proselyte armour.

Walkthrough: Sir Tiffy upgrades the Commorb to v2 -> Witchaven: O'Niall, Maledict, Hobb (Savant scan),
Holgart -> O'Niall again -> ruin west of the village, push the false wall, pick up the dead sea slug,
scan the imposing door with the Commorb v2 (opening it unscanned costs 5 damage) -> Jorral translates the
markings -> Page 1 (mayor's desk), Page 2 (Ezekial Lovecraft), Page 3 (O'Niall, torn in three) ->
hand the dead sea slug to Bailey (Fishing Platform) for sea slug glue -> glue on a fragment opens the
fragment puzzle (flip, rotate, move; select pieces) -> right-click each page to shape blank runes
(chisel + essence; success 43% at Runecraft 1 to 99% at 99, failure shatters) -> charge each at its altar
-> use the five runes on the door in any order -> Mother Mallum reveal / Slug Prince (level 62, 70 hp,
att/str/def 50, max hit 6, 4 ticks, melee only, drains prayer) -> Sir Tiffy.
