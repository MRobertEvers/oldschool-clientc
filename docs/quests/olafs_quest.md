# Olaf's Quest -- pinned brief

Source: OSRS wiki Olaf's Quest, oldid 15355207 (fetched 2026-10-02); Quest Helper
`helpers/quests/olafsquest/OlafsQuest.java`. LostCity has no copy (post-2004).

Requirements: The Fremennik Trials, Woodcutting 50, Firemaking 40 (boostable).
Combat: Skeleton Fremennik (lvl 40), Captain Ulfric (lvl 100, 60 hp).
Rewards: 1 QP, 12,000 Defence XP, 4 cut rubies, 20,000 coins (port), Brine Rat Cavern access.

Ladder: talk Olaf (stage 10) -> chop windswept tree log, give to Olaf (20) ->
Ingrid (bread) + Volf (shark) carvings (30) -> damp planks on embers, tinderbox (40)
-> Olaf asks for food (optional, any food; map given regardless) (50) -> dig beside
the tree (60) -> Skeleton Fremennik key -> picture wall lever puzzle (right, up,
left, down, bottom) -> 2 barrels + 6 ropes -> rotten walkway: per tile success
(Agility*0.86)+32.47+(falls*2.4)%, 78 Agility never falls -> gate, key shape lock
(wrong shape or a fall costs the key) -> chest -> Ulfric -> chest again (80).
