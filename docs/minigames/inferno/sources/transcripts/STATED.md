# What the Inferno guides state

Every number or rule below is a narrator's sentence, quoted from the auto-caption transcript in this directory with video id and `[mm:ss]` (`H:MM:SS` for long ones). Auto-captions mangle names: "Zuck" is Zuk, "Chad"/"Jab" is Jad, "major"/"midge" is mager, "block"/"bob" is blob, "male air"/"Miller" is melee. A narrator's number is grade D on its own; two guides agreeing is still one kind of source. Quotes follow the transcript, with caption punctuation added and the monster-name mangles above corrected in place (the transcript files keep the raw text, so search them by timestamp, not by the corrected word), and bracketed text and a few obvious name mangles ("major" for mager in Zuk-set sentences) are noted in place; where a quote is cut it ends in an ellipsis or `[...]`. Nothing here has been checked against the cache, the wiki or a recording. Where guides disagree both are listed under "Disagreements" in the unit.
