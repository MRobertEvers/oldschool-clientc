# Inferno techniques named by the pinned wiki strategy pages

Source tier: the wiki is a written guide (rank below Jagex and the cache, below recorders).
A technique is listed with the sentence that states it, the mechanic it rests on, and the
file and line of both. Every row is a test (WAVES_ORCHESTRATOR.md section 6, "the technique
rows"): the last column says what the tick log would have to show. Nothing here is a measured
value of our server; a number quoted here is the wiki's and is graded by the spec pass.

Pins used (all under `docs/minigames/inferno/sources/wiki/`, fetched 2026-10-03, revisions in
`manifest.tsv`):
