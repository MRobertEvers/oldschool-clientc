## Cannon Ammo notifications checkpoint

This hidden C plugin uses the major-3 server-tick, named-cache and notification APIs; it has no frame/panel contribution builder to retain. The native varp/varbit mappings remain revision-owned. The port audit found that a boolean `had_cannon` conflated different coordinates and treated native null (-1) as a cannon.
