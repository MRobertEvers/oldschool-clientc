# Translation units outside the APP LAYER that reach into `struct App`.
#
# The layer is src/app.c plus every unit under src/app/; they share the struct
# by design and are exempt.
#
# `python3 tools/appc_map.py check` fails on a reach-in that is NOT listed here,
# and also on a line here that has since become clean. So this file can only
# shrink: you cannot add a new reach-in without editing it, and you cannot fix
# one without deleting its line.
#
# Two of these are not defects. src/main.c and src/executor_config.c are the
# process host -- they construct the App and hand it the frame, which is what a
# host does. Everything else below is a module that was moved out of app.c and
# kept a pointer back in, and is a candidate for the parameter treatment.
#
# Recorded 2026-09-14 at v3 82f3e3e24, before the first Tier 0 extraction.
#
# And a second shrink-only number: how many top-level fields `struct App` is
# allowed to have. The list above cannot see the shape an extraction leaves
# behind -- a module that forward-declares `struct App` and keeps a pointer
# includes no header and names no type in a way that grep finds, while the
# state it should have taken sits in app.h exactly where it was. This number
# sees that. `check` fails when the struct grows past it AND when it has shrunk
# below it, so a field cannot creep back in on the space a subsystem freed.
