# Wasm functions that must stay small enough for JavaScriptCore to optimize.
#
# tools/wasm_func_size_check.py reads this after every web OPT=1 link and fails
# the build when one of these is over 90,000 bytes (JavaScriptCore's optimizing
# tier stops at 100,000: docs/web_wasm_function_size.md).
#
#   <name>            checked when the module has it (binaryen may inline it)
#   <name> required   must be in the module: its absence means binaryen folded
#                     it into its caller, which now carries its body
#
# The CS2 VM, per instruction. cs2vm2_run_script_body is the one loop: the hot
# and jit cases and (inlined by binaryen) the inline half of the handlers'
# switch; cs2vm2_run_op_outlined is the out-of-line half (CS2VM2_RUNOP_SPLIT).
cs2vm2_run_script_body required
cs2vm2_run_op_outlined required
CS2VM2_RunOp
cs2vm2_run_op_split

# The frame. binaryen folds every single-caller function under App_RunOnce into
# it; app_world_frame (the world step) and app_plugin_panel_tick (the plugin
# window and developer chrome) are kept as functions of their own
# (APP_WASM_OWN_FUNCTION, src/app/app_internal.h) so that all three stay under
# the limit.
App_RunOnce required
app_world_frame required
app_plugin_panel_tick required
