    What the terms mean

    painter
    how this engine draws: whole faces sorted back-to-front by depth, near ones painted over far ones. It cannot show two surfaces interleaving through each other.
    depth-tested / z-buffer
    resolves visibility per pixel instead of per face — the kind of renderer this 2012 model was authored for. Used here as the reference picture ("truth").
    priorities / bands
    per-face bytes that pin a face into a draw layer regardless of depth — the painter's crutch. The 2012 bytes were authored against a z-buffer, so they order nothing useful here.
    sort error
    % of the model's pixels where the painter shows a surface that is genuinely behind the true one.
    z-fighting / ties
    two faces at the same depth with no stable order — ownership of those pixels flips frame to frame (shimmer). Measured as contested pixels within ±2 depth units whose winner also flips when the draw order reverses; a contested pixel with a stable winner is layering, not fighting.
    flicker
    pixels that change between consecutive frames in the painter while the reference is still — z-fighting as the player would see it.
    cracks
    silhouette pixels one pipeline covers and the other doesn't. Should be ~0; nonzero means moved geometry opened a seam.
    bind pose
    the model as stored in the file, before any animation frame moves it.
    rig group / structure (g12)
    the set of vertices an animation moves as one unit (a jaw, a wing segment). Artifacts are attributed to pairs of these.
    patch (g12#3)
    one connected shell inside a rig group — faces joined by shared vertices. A group is often several shells stacked (a plate over the body it covers); the patch is what a z-fighting separation can actually move.
    depth levels
    the sort table's resolution: a model needs its whole posed diameter in levels or faces silently vanish. Reference engine: 1,500. DEPTH_16K: 16,384.
    order-check
    draw the depth-tested render twice with face order reversed; surviving differences are translucent faces, which blend in order by design. The floor no candidate beats.
    repair
    bounded whole-group moves (inflate a structure a few units) that separate fighting pairs — adopted only when measured ties drop and nothing else regresses.
