# ground-items, and the reason this file is separate.
#
# The plugin CANNOT START in an assert-enabled build. Its second
# expect_unsupported reason is 158 characters and PORCELAIN_DETAIL_MAX is 96,
# so Porcelain_CopyString's assert fires at on_start and the client aborts
# (SIGABRT, exit 134) before the first frame -- on BOTH lanes. Under NDEBUG the
# same call truncates silently, which is why the gate and the matrix, which are
# release builds, have never seen it. Run this file with
#
#   TORIRS_SHOT_BIN=<tree>/src/torirs_shotsrel  (OPT=1)
#
# and see tools/porcelain_gate/shots/detail_lengths.py, which finds it without
# running anything.
